# Support

Need help with an Avenix resource? Include these details so the issue can be understood clearly.

## Include these details

1. Resource name and version.
2. Framework and relevant dependency versions.
3. Exact error from the server console or client F8 console.
4. What you expected to happen.
5. What happened instead and the steps to reproduce it.
6. Relevant configuration, with private keys and credentials removed.

## Before contacting support

* Confirm documented dependencies are installed.
* Check the resource README and configuration.
* Restart the resource and review the first error in the console.
* Test whether the issue also occurs without unrelated custom changes.

Visit the [Avenix Studios website](https://avenix-studios-dev.base44.app/) for current contact and support options.

Never post server tokens, passwords, database credentials, or other private access details in a support request.
