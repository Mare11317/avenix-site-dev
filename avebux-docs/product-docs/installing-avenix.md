# Getting Started

This is the general workflow for adding an Avenix resource to a FiveM server. Always follow the README and configuration files included with the exact download.

## Before you begin

* Confirm you have access to the server files and server configuration.
* Check the included README for exact dependencies.
* Back up server files and the database before changing a live setup.
* Confirm the resource version.

## Installation workflow

1. Download and extract the resource. Keep its folder name unless its documentation says otherwise.
2. Check the README and fxmanifest. Install only the listed dependencies.
3. Review the resource configuration files.
4. Add the resource to server.cfg after its required dependencies.
5. Test in a development environment and check the server and client consoles.

If setup fails, visit Support and include the resource name, version, and relevant error text.
