# Avenix Studios Documentation

Welcome to the Avenix Studios resource documentation. Each resource will have its own page with setup instructions, configuration options, commands, permissions, and troubleshooting.

{% hint style="info" %}
Documentation is being organized by resource. Check each resource page for its supported version and requirements before installing or updating.
{% endhint %}

## How to use these docs

1. Open the page for the resource you are installing.
2. Check its requirements and supported framework.
3. Follow the installation steps in order.
4. Review the configuration reference before starting your server.
5. If you encounter an issue, use the troubleshooting section and include the full error message when asking for help.

More Avenix resources can be added as separate pages without mixing their instructions together.
